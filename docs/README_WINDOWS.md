# Bridge Local — Руководство оператора Windows (Серверный Агент)

Bridge Local для Windows — это фоновый агент и служба Windows (SCM Daemon), обеспечивающая удаленное выполнение команд PowerShell, мониторинг системных метрик и синхронизацию файлов («Карман») с клиентом на Linux.

---

## 1. Содержимое пакета

- `bridge-agent.exe` — скомпилированный автономный бинарный файл (не требует установленного Python).
- `setup_connection.bat` — интерактивный мастер настройки параметров (IP, порт, токен).
- `run_agent.bat` — запуск агента в отдельном консольном окне для отладки.
- `install_service.bat` — регистрация и автозапуск агента в качестве системной службы Windows.
- `uninstall_service.bat` — остановка и полное удаление системной службы и пунктов меню.
- `bridge.toml` — файл конфигурации агента.
- `README.md` — данная инструкция.
- `pocket\` — рабочий каталог кармана для обмена файлами.

---

## 2. Быстрый старт

### Шаг 1: Настройка подключения (`setup_connection.bat`)
1. Запустите двойным кликом файл `setup_connection.bat`.
2. Мастер автоматически определит локальные IPv4-адреса сетевых карт вашей Windows-машины (например, `192.168.1.150`).
3. Задайте или подтвердите порт (по умолчанию `9732`) и секретный токен PSK.
4. Мастер выведет готовую строку подключения для Linux:
   ```text
   ./bridge-cli connect 192.168.1.150:9732
   ```

### Шаг 2: Тестовый запуск (`run_agent.bat`)
1. Запустите `run_agent.bat`.
2. Откроется окно консоли с логами запуска сервера и привязки к порту `0.0.0.0:9732`.
3. Попробуйте выполнить ping с Linux-машины: `./bridge-cli ping`.
4. В окне агента появится отметка о входящем heartbeat-запросе и отправке Pong-ответа.

## 3. Установка в качестве системной службы (`install_service.bat`)

Для постоянной работы агента без открытых консольных окон (в том числе до экрана входа в Windows):
1. Кликните правой кнопкой мыши по `install_service.bat` и выберите **«Запуск от имени администратора»**.
2. Скрипт выполнит:
   - Регистрацию системной службы `BridgeLocalAgent` в диспетчере служб Windows (services.msc).
   - Интеграцию пункта **«Отправить в Карман (Bridge Local)»** в контекстное меню Проводника Windows (по правому клику на файл или папку).
   - Запуск службы с типом запуска «Автоматически».

Для удаления службы запустите `uninstall_service.bat` от имени администратора.

---

## 4. Контекстное меню Проводника (Direct File Drop)

После установки службы в контекстном меню Windows появится пункт:
- Правый клик на любой файл или папку -> **«Отправить в Карман (Bridge Local)»**.
- Файл немедленно копируется в локальный каталог `pocket\`.
- Фоновый монитор Watchdog автоматически регистрирует появление нового файла и передает его на Linux-машину.

---

## 5. Ручные команды CLI (через cmd / powershell)

Вы можете управлять агентом напрямую из командной строки Windows:
```cmd
:: Просмотр справки
bridge-agent.exe --help

:: Интерактивный мастер
bridge-agent.exe setup

:: Просмотр текущей конфигурации
bridge-agent.exe config show

:: Консольный запуск агента
bridge-agent.exe run

:: Ручная отправка файла в карман
bridge-agent.exe drop "C:\Files\document.pdf"

:: Управление системной службой
bridge-agent.exe service install
bridge-agent.exe service start
bridge-agent.exe service stop
bridge-agent.exe service remove
```

## 6. Безопасность и аудит

- **Защита по токену (HMAC SHA-256):** Любой запрос от Linux верифицируется криптографической подписью на основе общего секрета `psk_token` и временной метки с защитой от replay-атак.
- **Журнал аудита:** Все входящие вызовы команд PowerShell и файловые операции немедленно фиксируются с микросекундной точностью в журнале:
  `pocket\logs\YYYY-MM-DD.jsonl`
- **Изоляция и таймауты:** При превышении таймаута агент принудительно уничтожает все порожденные процессы с помощью Process Tree Killer (`taskkill /F /T`).

## 7. Устранение неполадок

1. **Linux не может подключиться (Connection refused / Timeout):**
   - Убедитесь, что служба запущена (в Диспетчере задач на вкладке «Службы» найдите `BridgeLocalAgent` со статусом «Работает»).
   - Добавьте правило входящих подключений для порта 9732 в Брандмауэре Windows:
     ```powershell
     New-NetFirewallRule -DisplayName "Bridge Local" -Direction Inbound -LocalPort 9732 -Protocol TCP -Action Allow
     ```
2. **Сеть с изоляцией клиентов (Client Isolation):**
   - Если машины подключены по Wi-Fi, некоторые роутеры блокируют трафик между беспроводными клиентами. Проверьте пинг между узлами: `ping 192.168.1.X`.
3. **Рассинхронизация часов (Dual Boot):**
   - При использовании Dual-boot проверьте соответствие времени между Windows и Linux (допустимое расхождение не более 60 секунд).
