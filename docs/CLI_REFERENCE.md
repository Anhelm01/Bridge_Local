# Справочник интерфейса командной строки Bridge Local (CLI & TUI)

Данный документ содержит исчерпывающее нормативное описание всех консольных интерфейсов платформы **Bridge Local**: клиентской утилиты Linux `bridge-cli`, утилиты серверного агента Windows `bridge-agent`, структуры параметров командной строки, спецификации режима `--json` и раскладки горячих клавиш терминального интерфейса (TUI).

---

## 1. Коды завершения процессов (Exit Codes)

Все консольные утилиты платформы возвращают строгие детерминированные целочисленные коды возврата (`sys.exit(code)`), определенные перечислением `bridge_client_linux.exit_codes.ExitCode`:

| Код | Символическое имя | Описание |
|:---:|:---|:---|
| **`0`** | `SUCCESS` | Команда успешно выполнена. Запрошенная операция завершена без ошибок. |
| **`1`** | `GENERAL_ERROR` | Неверные параметры командной строки, синтаксическая ошибка конфигурации `bridge.toml` или необработанное исключение. |
| **`2`** | `NETWORK_ERROR` | Целевой узел недоступен, сетевой порт закрыт, соединение отклонено (Connection Refused) или сокет сброшен сетью. |
| **`3`** | `AUTH_ERROR` | Несовпадение секретного токена PSK, сбой валидации контрольной подписи HMAC-SHA256, превышение допустимого дрейфа времени (>60 сек) или обнаружение повторной атаки (Replay Nonce). |
| **`4`** | `COMMAND_FAILED` | Дочерний процесс PowerShell на удаленном узле Windows завершился с ненулевым кодом выхода. |
| **`5`** | `TIMEOUT` | Превышен лимит времени выполнения команды PowerShell или ожидания ответа удаленного RPC-сервера. |

## 2. Стандарт для ИИ-операторов (`--json` режим)

Каждая команда `bridge-cli` поддерживает флаг `--json` (или краткую форму `-j`):
- **Машиночитаемый поток:** В поток `stdout` выводится строго валидный форматированный JSON-объект. Полностью исключены любые ANSI escape-последовательности, управляющие цветовые коды и псевдографические символы рамок.
- **Неблокирующее выполнение:** Утилита ни при каких обстоятельствах не ожидает пользовательского ввода на `stdin`.
- **Предсказуемая структура:** При успешном выполнении в JSON включаются результирующие структуры данных, а при ошибке — стандартизированный блок с кодом и типом ошибки.

### Пример успешного ответа (`bridge-cli exec "whoami" --json`):
```json
{
  "exit_code": 0,
  "stdout": "win-workstation\\admin\n",
  "stderr": "",
  "duration_ms": 28,
  "started_at": "2026-10-01T12:00:00.000000Z",
  "completed_at": "2026-10-01T12:00:00.028000Z",
  "timed_out": false,
  "encoding_detected": "utf-8"
}
```

### Пример ответа при ошибке сети (код выхода 2):
```json
{
  "status": "error",
  "error_code": 2,
  "error_type": "BridgeNetworkError",
  "message": "Connection refused to 192.168.1.150:9732"
}
```

### Пример ответа при ошибке команды PowerShell (код выхода 4):
```json
{
  "status": "error",
  "error_code": 4,
  "error_type": "BridgeRemoteCommandError",
  "message": "Remote PowerShell command failed with exit code 1",
  "cmd_exit_code": 1,
  "stdout": "",
  "stderr": "Get-Item: Cannot find path 'C:\\NonExistent' because it does not exist.\n"
}
```

## 3. Справочник утилиты клиента Linux: `bridge-cli`

### 3.1. Глобальные опции
- `--json`, `-j`: Включение машиночитаемого JSON-вывода.
- `--version`, `-v`: Отображение текущей версии платформы.
- `--config`, `-c <path>`: Явный путь к файлу конфигурации `bridge.toml`.
- `--host`, `-h <ip>`: Переопределение IP-адреса удаленного узла Windows.
- `--port`, `-p <port>`: Переопределение сетевого порта.
- `--token`, `-t <psk>`: Переопределение секретного токена PSK.
- `--node`, `-n <name>`: Переопределение имени целевого узла.

---

### 3.2. Корневые команды управления

#### `bridge-cli status`
Формирует сводный отчет о состоянии всех ключевых подсистем: качество сетевого соединения, задержка (RTT), показатели нагрузки удаленного узла (CPU, RAM, Uptime), статистика файлов кармана и количество новых заметок.
```bash
bridge-cli status
bridge-cli status --json
```

#### `bridge-cli ping`
Выполняет отправку зонда жизнеспособности (Heartbeat Ping) на удаленный агент с замером времени отклика (RTT).
```bash
bridge-cli ping
bridge-cli ping --count 5
bridge-cli ping --json
```
- `--count`, `-n <int>`: Число отправляемых зондов (от 1 до 10, по умолчанию: 1).

#### `bridge-cli exec`
Удаленное выполнение команд и сценариев в среде PowerShell на целевой Windows-машине.
```bash
# Базовое выполнение команды
bridge-cli exec "Get-Service -Name BridgeLocalAgent"

# Выполнение с ограничением по времени и без прав администратора
bridge-cli exec "dir C:\\" --timeout 15 --no-admin

# Выполнение с указанием рабочей директории
bridge-cli exec "git status" --dir "C:\\Projects\\Bridge_Local" --json
```
- `<command>` (обязательный аргумент): Текст команды для передачи в PowerShell.
- `--timeout`, `-T <int>`: Лимит времени выполнения в секундах (по умолчанию: 30). При превышении лимита удаленный процесс принудительно уничтожается.
- `--admin / --no-admin`: Запуск с повышенными привилегиями Администратора (по умолчанию: `--admin`).
- `--dir`, `-d <path>`: Рабочий каталог на диске Windows.

#### `bridge-cli send`
Прямая отправка одного или нескольких файлов в карман на стороне Windows (Direct File Drop).
```bash
# Отправка одного файла
bridge-cli send document.pdf

# Пакетная отправка нескольких файлов в подкаталог кармана
bridge-cli send archive.zip image.png log.txt --target-dir "incoming"
```
- `<files...>` (обязательные аргументы): Список путей к отправляемым локальным файлам.
- `--target-dir`, `-d <string>`: Относительный подкаталог внутри удаленного кармана.

#### `bridge-cli welcome`
Вывод полноэкранного экрана приветствия BRIDGES Master с неофетч-сводкой системных параметров.
```bash
bridge-cli welcome
```

#### `bridge-cli tui`
Запуск полноэкранного интерактивного терминального интерфейса.
```bash
bridge-cli tui
bridge-cli tui --mode NOTES
bridge-cli tui --single-pass
```
- `--mode`, `-m <string>`: Начальная активная вкладка при открытии (`SPLASH`, `DASH`, `POCKET`, `NOTES`, `EXEC`, `CONFIG`, `DEV`, `CONNECT`). По умолчанию `DASH`.
- `--single-pass`: Однократная отрисовка кадра без входа в блокирующий цикл событий (для CI и скриптов).

#### `bridge-cli connect`
Быстрое подключение к новому адресу Windows-узла без ручного редактирования TOML-файла.
```bash
bridge-cli connect 192.168.1.150:9732
bridge-cli connect 192.168.1.150:9732 --token "MySecretKey"
```
- `<target>`: Сетевой адрес целевого узла (`IP:порт` или `IP`).
- `--token`, `-t <string>`: Секретный токен PSK (опционально).

#### `bridge-cli setup`
Интерактивный пошаговый мастер настройки сетевого подключения в терминале.
```bash
bridge-cli setup
```

### 3.3. Подкоманды управления карманом: `bridge-cli pocket`

#### `bridge-cli pocket status`
Отображает локальный путь к карману, число файлов, общий объем и списки файлов в очередях PULL (скачивание) и PUSH (отдача).
```bash
bridge-cli pocket status
bridge-cli pocket status --json
```

#### `bridge-cli pocket sync`
Запуск процесса синхронизации содержимого кармана между узлами.
```bash
bridge-cli pocket sync
bridge-cli pocket sync --direction push
bridge-cli pocket sync --direction pull
```
- `--direction`, `-d`: Направление синхронизации (`both`, `push`, `pull`). По умолчанию `both`.

#### `bridge-cli pocket push`
Загрузка конкретного локального файла в удаленный карман.
```bash
bridge-cli pocket push ./build/dist.tar.gz --target "releases/dist.tar.gz"
```
- `<file_path>`: Путь к исходному файлу на локальном диске.
- `--target`, `-t <path>`: Относительный путь назначения в удаленном кармане.

#### `bridge-cli pocket pull`
Скачивание конкретного файла из удаленного кармана на локальную машину.
```bash
bridge-cli pocket pull "logs/agent.log" --dest ./agent.log
```
- `<remote_file>`: Относительный путь к файлу в удаленном кармане.
- `--dest`, `-d <path>`: Локальный путь для сохранения файла.

---

### 3.4. Подкоманды управления заметками: `bridge-cli note`

#### `bridge-cli note send`
Отправка текстового сообщения, сниппета или гиперссылки на удаленный узел.
```bash
bridge-cli note send "https://github.com/Anhelm01/Bridge_Local/issues/10"
bridge-cli note send "Проверь порт 9732" --to "WIN-PC"
```
- `<text>`: Содержимое заметки.
- `--to`, `-t <node>`: Идентификатор целевого узла (опционально).

#### `bridge-cli note list`
Просмотр журнала переданных и полученных заметок.
```bash
bridge-cli note list --limit 15
bridge-cli note list --unread
```
- `--limit`, `-l <int>`: Максимальное количество записей (по умолчанию: 20).
- `--unread`, `-u`: Отображать только непрочитанные заметки.

#### `bridge-cli note read`
Квитирование прочтения одной или нескольких заметок по их идентификаторам.
```bash
bridge-cli note read "e9a03bc2-44df-4416-8f3a-cb28646b1a11"
```

---

### 3.5. Подкоманды конфигурации: `bridge-cli config`

#### `bridge-cli config show`
Вывод текущей активной конфигурации в формате TOML или структурированном JSON.
```bash
bridge-cli config show
bridge-cli config show --json
```

#### `bridge-cli config set`
Оперативное изменение сетевых параметров в файле `bridge.toml` через командную строку.
```bash
bridge-cli config set --host 192.168.1.155 --port 9735
bridge-cli config set --token "NewPskKey2026"
```
- `--host`, `-h <ip>`: Новый IP-адрес или имя хоста.
- `--port`, `-p <int>`: Новый сетевой порт TCP.
- `--token`, `-t <string>`: Новый секретный ключ PSK.

## 4. Справочник утилиты агента Windows: `bridge-agent`

Консольная утилита управления и администрирования на стороне операционной системы Windows.

```powershell
bridge-agent [команда] [аргументы]
```

### 4.1. Доступные команды `bridge-agent`

| Команда | Описание |
|:---|:---|
| **`bridge-agent setup`** | Интерактивный мастер первоначальной настройки агента с автоматическим определением локальных сетевых адаптеров и адресов IPv4. |
| **`bridge-agent config show`** | Отображение активного конфигурационного файла `bridge.toml`. |
| **`bridge-agent config set`** | Изменение настроек хоста, порта и токена PSK в `bridge.toml`. |
| **`bridge-agent run`** | Консольный запуск агента в текущем терминале Windows (режим отладки). Выводит трассировку пакетов в реальном времени. Прерывается по `Ctrl+C`. |
| **`bridge-agent service-run`** | Запуск внутреннего рабочего цикла службы под управлением Service Control Manager (SCM). Вызывается самой ОС при старте службы. |
| **`bridge-agent service install`** | Регистрация службы `BridgeLocalAgent` в реестре Windows SCM с автоматическим типом запуска. |
| **`bridge-agent service start`** | Запуск зарегистрированной системной службы `BridgeLocalAgent`. |
| **`bridge-agent service stop`** | Остановка запущенной системной службы `BridgeLocalAgent`. |
| **`bridge-agent service remove`** | Полное удаление регистрации службы `BridgeLocalAgent` из реестра Windows. |
| **`bridge-agent drop <path>`** | Копирование локального файла или директории в каталог кармана (`pocket/`). |
| **`bridge-agent install-context-menu`** | Регистрация пункта «Отправить в Карман (Bridge Local)» в контекстном меню Проводника Windows (`HKCU\Software\Classes\*\shell\BridgeDrop`). |
| **`bridge-agent uninstall-context-menu`**| Удаление пункта контекстного меню Проводника Windows из реестра. |
| **`bridge-agent generate-reg [out.reg]`** | Экспорт настроек контекстного меню в файл реестра `.reg` для ручного применения без прав администратора. |

## 5. Горячие клавиши и навигация в терминальном TUI

Терминальный интерфейс (`bridge-cli tui`) предоставляет полноэкранное рабочее пространство с поддержкой аппаратных клавиш управления:

### 5.1. Навигация по вкладкам (Стрелки ← / →, Цифры 1..8, Tab, F1..F8)

| Клавиши | Вкладка | Назначение |
|:---:|:---|:---|
| **`1`** / `F1` | `SPLASH` | Экран приветствия BRIDGES Master и аппаратная Neofetch-сводка. |
| **`2`** / `F2` | `DASH` | Оперативный дашборд: сводка сетевого канала, метрики узла Windows, состояние очередей. |
| **`3`** / `F3` | `POCKET` | Просмотр хранилища кармана, статусов файлов и строка прямой отправки (`PUSH FILE >`). |
| **`4`** / `F4` | `NOTES` | Лента входящих и исходящих заметок, строка ввода новой заметки (`NOTE >`). |
| **`5`** / `F5` | `EXEC` | Удаленный терминал PowerShell: журнал выполненных команд и строка ввода (`PS C:\>`). |
| **`6`** / `F6` | `CONFIG` | Таблица зарегистрированных узлов сети, сетевых адресов и параметров аутентификации. |
| **`7`** / `F7` | `DEV` | Системный журнал трассировки ядра, параметров сокетов и абсолютных путей. |
| **`8`** / `F8` | `CONNECT` | Быстрая перенастройка целевого узла (IP, порт, токен) без выхода из TUI. |

### 5.2. Клавиши управления и навигации

- **`Стрелка Влево` (`←`) / `Стрелка Вправо` (`→`):** Мгновенное переключение на предыдущую / следующую вкладку (работает прямо на клавиатуре без Fn).
- **`Цифры 1..8`:** Прямой переход на вкладку 1..8 в режимах просмотра (SPLASH, DASH, CONFIG, DEV), а также в POCKET/NOTES/EXEC при пустом поле ввода (или через `Alt+1`..`Alt+8` отовсюду).
- **`Tab` / `Shift+Tab`:** Циклическое переключение вперед / назад между всеми 8 вкладками.
- **`[` / `]`:** Переход на предыдущую / следующую вкладку в режимах просмотра.
- **`Стрелка Вверх` (`↑`) / `Стрелка Вниз` (`↓`):** Построчный вертикальный скроллинг длинных списков файлов в POCKET, ленты заметок в NOTES, вывода команд в EXEC и журнала в DEV.
- **`Page Up` / `Page Down`:** Постраничный скроллинг содержимого.
- **`Home` / `End`:** Переход в начало / в конец списка.
- **`Enter`:** Отправка команды, пути к файлу или текста заметки из активной строки ввода.
- **`Escape`:** Очистка содержимого текущего поля ввода; если поле ввода пусто — возврат на главную вкладку DASH.
- **`Ctrl+C` / `Ctrl+Q`:** Корректный выход из TUI с закрытием альтернативного экранного буфера.
- **Команды двоеточия (`:1`..`:8`, `:dash`, `:pocket`, `:notes`, `:exec`, `:q`):** Быстрый переход и выход из любого поля ввода.
