# 05_BINARY_GUIDE_WINDOWS: Windows Standalone Binary Guide

Полное руководство по развертыванию, конфигурации, оперированию и системной интеграции предварительно скомпилированного / автономного исполняемого файла агента **`bridge-agent.exe`** на операционной системе Windows (без необходимости установки Python, компиляторов и зависимостей).

---

## 1. Обзор автономного пакета Windows

Автономная сборка агента Bridge Local представляет собой независимый бинарный дистрибутив:
- **Исполняемый файл**: `dist\bridge-agent.exe` (или `C:\BridgeLocal\bridge-agent.exe`)
- **Консоль управления**: `start.bat` (ультимативная панель управления CMD/PowerShell)
- **Файл настроек**: `bridge.toml`
- **Запуск трея**: `run_tray.bat` и `scripts\windows\run_hidden.vbs`
- **Общее хранилище**: `pocket\` (включая журнал заметок `.notes\journal.db`)

Бинарный файл `bridge-agent.exe` скомпилирован с помощью PyInstaller, включает встроенный изолированный рантайм, системные DLL `pywin32` и работает на любых системах Windows 10/11 x64 "из коробки".

---

## 2. Быстрый старт в один клик (`start.bat`)

Для первоначального запуска и автоматической настройки всех компонентов дважды кликните файл **`start.bat`** (или запустите его в командной строке).

```cmd
start.bat
```

*Интерфейс панели управления Windows:*
```text
==============================================================================
                  BRIDGE LOCAL - WINDOWS CONTROL CENTER
==============================================================================
 Privilege Level: [ADMINISTRATOR] - Full access to SCM, registry, and firewall
------------------------------------------------------------------------------
 Installation Root: C:\BridgeLocal\
 Service BridgeLocalAgent: [STOPPED]
 Firewall Port 9732 TCP:   [ALLOWED OK]
==============================================================================

  [1] QUICK START (Recommended)
      --> Open port 9732 in Windows Firewall (All profiles)
      --> Register "Send to Pocket" in Windows Explorer context menu
      --> Launch Bridge Local Agent in interactive console

  [2] INSTALL AS BACKGROUND WINDOWS SERVICE (SCM)
      --> Full auto-setup + agent runs silently in background on boot

  [3] Run Agent in Console (Live Monitor and interactive prompt)
  [4] Network and Pocket Configuration Wizard (Port, Token, Pocket path)
  [5] Global Windows System Setup (PATH + BRIDGE_CONFIG + C:\BridgeLocal)
  [6] Manage Windows Service (SCM: Start / Stop / Restart / Status)
  [7] Configure Windows Firewall (Open port 9732 TCP)
  [8] Explorer Context Menu Integration ("Send to Pocket")
  [9] Windows System Tray and Autostart (shell:startup)
  [10] Rebuild Standalone Executable (bridge-agent.exe via PyInstaller)
  [11] Uninstall and Clean Up (Service, Menu, Firewall, Autostart)
  [12] Drop Clipboard to Pocket (send copied files or text to Pocket)

  [0] Exit
==============================================================================
Select an option [default: 1]: 
```

### Рекомендуемый выбор: пункт `[1] QUICK START`
Скрипт автоматически выполнит:
1. Запрос прав Администратора (UAC) при необходимости.
2. Создание разрешающего правила в Брандмауэре Windows для входящего TCP-порта `9732`.
3. Настройку сетевого профиля как "Частная сеть" (Private Network).
4. Регистрацию пункта «Отправить в Карман» в Проводнике Windows.
5. Запуск агента в режиме интерактивной консоли **Live Monitor**.

## 3. Справочник функций консоли управления (`start.bat`)

| Пункт | Название | Назначение |
|---|---|---|
| **`[1]`** | **QUICK START** | Автоматическая комплексная настройка брандмауэра, контекстного меню и запуск агента. |
| **`[2]`** | **INSTALL AS SERVICE** | Регистрация и запуск агента как системной службы Windows Service (SCM). Агент будет работать в фоне даже без входа пользователя в систему. |
| **`[3]`** | **Run Agent in Console** | Запуск `bridge-agent.exe run` с отображением экрана мониторинга и командной строки оператора. |
| **`[4]`** | **Configuration Wizard** | Пошаговый мастер изменения сетевого порта, секретного токена и пути к каталогу Кармана. |
| **`[5]`** | **Global Windows Setup** | Развертывание бинарника в стандартный системный каталог `C:\BridgeLocal`, добавление в глобальный системный `PATH` и установка переменной `BRIDGE_CONFIG`. |
| **`[6]`** | **Manage Windows Service** | Меню управления службой SCM: Просмотр статуса, Запуск (`Start`), Остановка (`Stop`), Перезапуск (`Restart`). |
| **`[7]`** | **Configure Firewall** | Открытие входящего порта 9732 TCP во всех профилях брандмауэра Windows Defender. |
| **`[8]`** | **Context Menu Integration** | Установка или удаление пункта контекстного меню Проводника «Отправить в Карман (Bridge Local)». |
| **`[9]`** | **System Tray & Autostart** | Запуск значка в системном трее Windows и добавление его ярлыка в автозагрузку (`shell:startup`). |
| **`[10]`**| **Rebuild Executable** | Локальная пересборка `bridge-agent.exe` через PyInstaller с защитой от блокировки занятых файлов. |
| **`[11]`**| **Uninstall and Clean Up** | Полная очистка системы: удаление службы, пунктов меню, правила брандмауэра и автозапуска. |
| **`[12]`**| **Drop Clipboard to Pocket** | Мгновенный перенос содержимого буфера обмена (скопированные файлы, скриншоты, текст) в Карман. |

## 4. Развертывание в качестве системной службы Windows (SCM)

Если вы хотите, чтобы Windows-агент работал незаметно в фоновом режиме, запускался автоматически при включении компьютера и не требовал открытых консольных окон:

### 4.1 Установка службы через CLI
Запустите командную строку или PowerShell от имени **Администратора**:

```powershell
# Установка службы в Service Control Manager
.\dist\bridge-agent.exe service install

# Запуск службы
.\dist\bridge-agent.exe service start
```

### 4.2 Управление через стандартные средства Windows
Служба зарегистрирована под именем `BridgeLocalAgent`:

```powershell
# Проверка статуса
sc query BridgeLocalAgent

# Запуск и остановка
net start BridgeLocalAgent
net stop BridgeLocalAgent

# Либо через оснастку служб Windows:
services.msc
```

### 4.3 Логирование службы
В фоновом режиме работы службы весь вывод и диагностические сообщения направляются в лог-файл:
```text
pocket\logs\agent_service.log
```

## 5. Интеграция с Проводником и Системным буфером

### 5.1 Контекстное меню Проводника
После установки (пункт `[8]` в `start.bat` или команда `bridge-agent install-context-menu`):
1. Откройте Проводник Windows (`Win+E`).
2. Нажмите правой кнопкой мыши на любой файл, несколько файлов или папку.
3. Выберите пункт **«Отправить в Карман (Bridge Local)»**.
4. Файл моментально копируется в каталог `pocket\`, откуда Linux-клиент автоматически подтягивает его.

### 5.2 Отправка из системного буфера обмена (Clipboard Drop)
Bridge Local поддерживает прямое извлечение объектов из буфера обмена Windows:
- **Скопированные файлы**: выделите файл в Проводнике и нажмите `Ctrl+C`.
- **Скриншоты и изображения**: нажмите `Win+Shift+S` и выделите область экрана.
- **Текст и ссылки**: скопируйте URL из адресной строки браузера.

Чтобы отправить содержимое буфера в Карман:
- Выберите пункт **`[12]`** в `start.bat` (или выполните `start.bat clip`).
- Либо нажмите правой кнопкой мыши на значок Bridge Local в системном трее и выберите **«Вставить из буфера в Карман»**.
- Либо выполните в консоли:
  ```powershell
  .\dist\bridge-agent.exe drop --clipboard
  ```

## 6. Значок в системном трее Windows (`tray.py`)

Значок в трее обеспечивает фоновое присутствие и быстрый доступ к функциям без открытия консоли:
1. Запуск значка трея:
   ```cmd
   run_tray.bat
   ```
2. Значок появляется в правом нижнем углу панели задач (область уведомлений).
3. **Меню трея по правому клику:**
   - **Открыть Карман**: открывает локальную папку `pocket\` в новом окне Проводника.
   - **Вставить из буфера в Карман**: сохраняет скопированный файл/текст в Карман.
   - **Статус службы**: отображает всплывающее уведомление о состоянии сервера.
   - **Служба SCM (Запустить / Остановить)**: быстрое переключение фоновой службы.
   - **Выход**: закрытие значка.

### Добавление в автозагрузку при входе в Windows:
В меню `start.bat` выберите пункт `[9]` -> `[2] Add Tray icon to Windows Startup`.
Скрипт создаст ярлык `BridgeLocalTray.lnk` в каталоге `shell:startup`, запускающий трей в скрытом режиме без всплывающих окон CMD.

## 7. Глобальное развертывание в систему (`C:\BridgeLocal`)

Для удобства повседневного использования рекомендуется развернуть утилиту в системный каталог `C:\BridgeLocal`:

В меню `start.bat` выберите пункт **`[5]` -> `[4] Complete global setup`**.

Скрипт автоматически:
1. Создаст директорию `C:\BridgeLocal`.
2. Скопирует туда `bridge-agent.exe`, `bridge.toml` и создаст `C:\BridgeLocal\pocket`.
3. Добавит `C:\BridgeLocal` в общесистемную переменную **`PATH`**.
4. Установит постоянную системную переменную среды **`BRIDGE_CONFIG=C:\BridgeLocal\bridge.toml`**.

**Результат:** команда `bridge-agent` становится доступна из любой папки в любой консоли Windows (CMD, PowerShell, Терминал):
```powershell
bridge-agent drop "C:\files\data.zip"
bridge-agent drop --clipboard
bridge-agent run
```

## 9. Устранение неполадок (Troubleshooting)

### 9.1 Окно консоли сразу гаснет при запуске
- В предыдущих версиях окно гасло при запуске `bridge-agent.exe` без аргументов или при занятом порте.
- **В актуальной версии:**
  - Запуск без параметров автоматически открывает интерактивную консоль **Live Monitor**.
  - При ошибке привязки к порту выводится подробное предупреждение на русском языке и запрос `Нажмите Enter для выхода...`. Окно больше никогда не гаснет самопроизвольно.

### 9.2 Ошибка «Порт 9732 уже используется другим процессом» (`WinError 10048`)
Это означает, что агент уже работает в фоновом режиме (как служба SCM либо в другом окне):
1. Проверьте, запущена ли служба:
   ```powershell
   sc query BridgeLocalAgent
   ```
   Если служба работает (`RUNNING`), остановите её перед ручным запуском консоли:
   ```powershell
   net stop BridgeLocalAgent
   ```
2. Либо завершите фоновые процессы через Диспетчер задач (вкладка «Подробности» -> `bridge-agent.exe`).

### 9.3 Блокировка антивирусом или Windows SmartScreen
Поскольку файл скомпилирован с помощью PyInstaller без цифровой подписи (EV-сертификата), Windows SmartScreen или антивирус может выдать предупреждение:
1. В окне SmartScreen нажмите **«Подробнее»** -> **«Выполнить в любом случае»**.
2. Добавьте каталог `C:\BridgeLocal` в исключения Защитника Windows (Windows Security -> Защита от вирусов и угроз -> Управление настройками -> Исключения).

### 9.4 Полное удаление из системы
Чтобы полностью вернуть систему в исходное состояние, запустите `start.bat` и выберите пункт **`[11] Uninstall and Clean Up`**. Будут удалены служба, правила брандмауэра, пункты контекстного меню и ярлыки автозапуска.
