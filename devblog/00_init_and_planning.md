## 3. Принятые архитектурные решения и регламент
1. **Поэтапное выполнение без спешки:**
   - Отказ от монолитного одновременного запуска всех агентов.
   - Движение строго фаза за фазой.
   - Каждая фаза и подфаза завершается подробным отчетом в `devblog/`.
2. **Структура референсов и заметок:**
   - [ref/Hum/](file:///home/anhelm/Projects/Bridge_Local/ref/Hum/) — для пользовательских референсов по дизайну и реализации.
   - [ref/AI/](file:///home/anhelm/Projects/Bridge_Local/ref/AI/) — для аналитических заметок, предложений и додумок со стороны ИИ.
3. **Dev-Mode Hyper-Logging:**
   - В систему на этапе разработки закладывается максимальное количество структурированных логгеров (сетевые сокеты, I/O буферы, PowerShell-вызовы, события heartbeat, операции с файлами кармана).
   - Это гарантирует простую локализацию ошибок на этапе отладки.
   - Для релизной сборки на Git логирование изолируется на уровне конфигурации (TRACE/DEBUG vs INFO).
4. **Хранилище документации:**
   - Полный план SDLC зафиксирован в [docs/SDLC_PLAN.md](file:///home/anhelm/Projects/Bridge_Local/docs/SDLC_PLAN.md).
