# 🌉 BRIDGE LOCAL

> **Прямой мост между твоим Linux и Windows по домашней сети.**  
> *Без облаков. Без флешек. Без танцев с бубном.*

---

## 🎯 Что это такое?

У тебя рабочий ноутбук на **Linux**, а рядом мощный игровой ПК на **Windows**?  
Надоело кидать файлы самому себе в Telegram, втыкать флешку или настраивать капризные сетевые папки Windows?

**Bridge Local** связывает обе машины в единую систему. Ты работаешь за Linux, а второй компьютер становится твоим продолжением.

---

## 🔥 Что внутри «коробки»

### 📂 1. Общий «Карман» (Pocket)
*Кинул — и оно уже там.*
* Перетащил любой файл в папку `pocket` на Linux — через секунду он на Windows.
* На Windows кликнул правой кнопкой по любому файлу ➔ **«Отправить в карман»** — и он уже у тебя в Linux.
* Скопировал текст или файл в буфер обмена ➔ одной кнопкой закинул на соседний ПК.

### ⚡ 2. Симметричный пульт управления прямо из консоли
*Рули вторым компом не вставая со стула — в любую сторону.*
* **С Linux на Windows**: запустить игру, рендер, билд или тяжелую софтину:
  ```bash
  bridge-cli exec "Start-Process 'C:\Games\Game.exe'"
  ```
* **С Windows на Linux**: выполнить bash-скрипт или проверить службы на Linux:
  ```cmd
  bridge-agent exec "uname -a; df -h"
  ```
* Завершить зависший процесс, посмотреть файлы (`ls`, `find`) — всё мгновенно и без задержек.

### 💬 3. Быстрые записки между экранами
*Перекинул ссылку или сниппет кода за 1 секунду.*
* Отправить заметку на второй экран:
  ```bash
  bridge-cli note send "https://youtube.com/watch?v=..."
  ```
* Никаких мессенджеров, аккаунтов и интернета.

### 🔒 4. 100% Локально и безопасно
*Твои данные принадлежат только тебе.*
* Работает напрямую по локальной сети (по проводу или Wi-Fi) на максимальной скорости твоей сетевой карты.
* Никакой привязки к серверам или интернету.
* Вся связь защищена секретным ключом.

### 🤖 5. Создано для людей и готово для ИИ
* Хочешь сам? Для человека есть красивое меню в терминале Linux и иконка в трее Windows у часов.
* Хочешь поручить ИИ? Любой терминальный агент (Antigravity, Claude и др.) умеет управлять Windows через понятные JSON-команды.

## 📦 Быстрый старт за 1 минуту

1. **На Windows**: распаковал папку, запустил `start.bat` ➔ нажал **[1] Быстрый старт**.
2. **На Linux**: распаковал папку, ввел:
   ```bash
   ./bridge-cli connect 192.168.1.XXX:9732
   ```
3. **Готово!** Связь установлена.

---

### 💻 Системные требования:
* **Linux**: Любой 64-битный дистрибутив.
* **Windows**: Windows 10 или 11 (64-бит).
* **Сеть**: Домашний роутер (Wi-Fi или кабель LAN).
* **Зависимости**: Ноль. Работает автономно прямо из архива.
